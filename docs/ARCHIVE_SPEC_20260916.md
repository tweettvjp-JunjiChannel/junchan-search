# 順ちゃんワールド（junchan-world.com）UI/UX＆システム設計確定仕様書

**作成日**: 2026-09-16  
**ステータス**: 本番検証・デプロイ完了（コミット: 51fb224）

## 1. Codoc認証・購入動線の基本原則
- **1ページ1マウント制約の遵守**: Codoc決済スクリプト（cms.js / .wp-block-codoc-codoc-block）は1ページに複数配置すると衝突するため、本文直前の境界線1箇所に完全集約。
- **有料記事**:
  - 記事冒頭の古い赤枠（auto_sync_blogs埋め込み）はCSS（`:has()`）で完全非表示。
  - 有料ライン直前に、順ちゃん顔アイコン付きの「統合案内枠（月額・単品・他デバイスでの復元案内）」を配置。
  - 復元ボタン表記: 「🔄 ログインして購入済みを復元する」
- **無料記事**:
  - 本文中に有料Codocブロックは配置せず、冒頭の月間サブスク案内および復元リンクのみを維持。

## 2. サイドバー構造と状態保持
- **最上部看板枠**: 「300冊の宝島」バナーを静的HTML/CSSとして配置。Codocスクリプトや決済ボタンは一切排除し、各記事での購入手順を案内する看板に徹する。
- **重複ボタンの全廃**: 最上部にあった「購読の確認・解約」ボタンを撤去し、検索ボックス直下のみに一本化。
- **検索キーワードの永続化**:
  - `sessionStorage (nseb_search_keyword)` を利用。
  - タグ遷移（`/tag/`）やカテゴリ遷移でURLから `?s=` が消失しても、検索窓（input）に入力値を自動復元。
  - クリアボタン（×）押下時のみ明示的に記憶を消去。

## 3. 関連記事（related-entries）配信ロジック
- **除外設定**: TweetTV関連カテゴリー（ID: 2447, 2457, 2456）およびアイキャッチ画像無しの記事を完全除外。
- **ランダム性の排除**: `orderby => 'rand'` を廃止し、公開日順（date DESC）による決定論的表示に変更。
- **2段階自動補填ロジック**:
  - 同一タグ・子カテゴリの記事が6件未満の場合、サイト全体の有効なnote記事から重複なく最新順に補填。
  - いかなる記事でも【必ず正確に6件】の表示を保証。
- **自記事除外とUIクリーンアップ**:
  - 現在閲覧中の投稿ID（`get_the_ID()`）をクエリ・補填の両方で完全に除外。
  - 記事直下の「前後の記事ナビゲーション（`.pager-post-navi`）」を非表示化し、関連記事との重複錯覚を解消。
